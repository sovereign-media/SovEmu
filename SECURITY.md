# Security

Please report a vulnerability privately, through GitHub's
[private vulnerability reporting](https://github.com/sovereign-media/SovEmu/security/advisories/new)
(Security → Report a vulnerability), not in a public issue or pull request.

Say what is affected (the server, a worker, the web client or an app, and the version or image
tag), how to reproduce it, and what it lets an attacker do. You will get an answer within a week.

Only the latest image (`ghcr.io/sovereign-media/sovemu:bleeding`) and `main` get fixes.

Out of scope: the emulator cores themselves (report those to their libretro projects), and a
server exposed to the internet without TLS in front of it.
